# Docs

The documentation follows the [Diátaxis](https://diataxis.fr) framework. Pick the section that matches what you need.

| I want to…                              | Read                                         |
| --------------------------------------- | -------------------------------------------- |
| Get the project running for the first time | [Tutorials](tutorials/)                   |
| Accomplish a specific task              | [How-to guides](how-to/)                     |
| Look up a command, setting or table     | [Reference](reference/)                      |
| Understand why it works the way it does | [Explanation](explanation/)                  |

## Project records

- `specs/NNN-title.md`: one feature per file (goal, scope, acceptance criteria, status). Spec status values: `draft` → `ready` → `in-progress` → `done`.
- `adr/NNN-title.md`: architecture decisions, one per file.
- `../GLOSSARY.md`: domain terms. Use these names exactly in code and docs.
